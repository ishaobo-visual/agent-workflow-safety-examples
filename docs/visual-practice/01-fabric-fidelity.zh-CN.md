# 修正生成服装的假织纹，同时保留真实面料感

根据2026年10月的单人针织图像编辑记录整理的匿名实践案例。本文没有附带原始商业图片、人物参考、商品标识、账号、请求凭据或私有路径；因此目前是方法说明，不是读者可独立复核画面的完整图像基准。

## 问题

一张人物、动作和场景已经满意的生成图片，衣服仍可能出现卷曲虫纹、夸张颗粒或云团斑块。目标是依据同款实拍恢复可信的针织组织和尺度，同时尽量保住已认可的画面。真实混纱、绒毛与自然不规则不应一概当成缺陷删除。

## 实际试验方法

历史试验使用KIE的`nano-banana-pro`，2K、3:4、PNG。这是当时的具体条件，不代表其他模型、当前服务配置或固定成功率。

获认可的母版优先编辑采用五张参考，顺序与职责为：

1. 已认可母版：实际外貌、肤色、姿态、构图和场景的依据，并明确它是编辑对象。
2. 同款完整实拍：衣服结构、颜色、组织分区与整体尺度的依据。
3. 同款原像素细节：用于辨识真实织纹，不能把局部放大比例误当整件衣服的针目大小。
4. 主身份参考：辅助身份一致性。
5. 相容角度身份参考：辅助当前角度的外貌，不替代母版的画面权威。

允许重建原图中错误的衣料；保留商品正确的结构和原画面已经认可的事实。逐款描述前片与袖子的组织分区、领口、袖口、门襟等，不把一种针织结构复制到所有商品。

先检查生成返回的衣料、人物与画面，再在有必要时做衣服范围内的小幅校色。材质未修好时，校色不能替代修复。

## 记录支持什么

- 同一款商品的两次五图母版优先编辑结果获用户认可，认可范围为正常观看时的人物、肤色、动作、背景保持及整体效果，不要求逐像素相同。
- 后续另一款平针商品的限定校色成片获认可；该款的编辑观察记录指出卷曲纹明显消退。另有细竖针路款的认可记录，支持继续按各款真实组织迁移。
- 早期复现也出现过“衣料改善、桌杯和场景却改变”的结果。它支持材质处理的可行性，却不满足保留原画面的目标。
- 当前材料不能计算跨款稳定成功率，也不能把改进单独归因于参考排序、某句提示词或身份参考数量。生成服务的随机性及内部实现未被控制。

## 复用时应保留的检查

| 检查对象 | 要回答的问题 |
| --- | --- |
| 面料 | 组织、尺度与真实商品相符吗？是修正假纹理，还是仅把画面磨平？ |
| 商品结构 | 前片与袖子有无串纹？领袖口、扣数、门襟与标记是否正确？ |
| 人物 | 身份、肤色、头发、手和姿态是否发生不能接受的变化？ |
| 场景与融合 | 道具位置、光线、衣领与皮肤接触、手衣遮挡是否保持可信？ |
| 后处理 | 校色是否只作用于目标衣服？颜色是否符合现场光线？ |
| 验收 | 通过的是面料局部、人物保持，还是这一个精确最终版本的整体效果？ |

衣服限定校色的“区外零像素变化”只说明校色步骤没有改动其他区域，不证明模型编辑前后整图不变。正常观看认可也不能被事后新增的逐像素一致标准撤销。

## 其他值得一起分享的经验

本案例可作为商业视觉实践集的第一篇。后续主题包括：局部返修时冻结已认可事实；区分人物身份相似与光线、透视、接触关系自然；精确版本验收和闭集交付；保留失败对照，避免重复尝试已经证伪的条件。后续各篇应分别核对自身证据，不由本案例自动背书。
