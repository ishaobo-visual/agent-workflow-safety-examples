# 商业图质量检查：技术通过之后还要看什么

这是从服装图片实际反馈中整理的检查框架，不是自动评分模型。检查表本身没有经过公开盲测，不报告总体准确率或漏检率。原商业图片未随文发布。

## 七个观察维度

| 维度 | 具体观察 |
| --- | --- |
| 商品真实 | 款式、颜色、结构与材质符合本款实物，关键细节清楚 |
| 人物可信 | 身份稳定、比例与动作协调，表情和视线有自然反应 |
| 融合自然 | 透视、尺度、光照、接触阴影、遮挡及成像质感属于同一空间 |
| 构图舒服 | 主次和留白合理，裁切不破坏需要展示的人物与商品 |
| 光色可靠 | 肤色与商品色可信，材质有层次，不靠磨皮或过锐制造质感 |
| 表达有效 | 搭配、地点与行为符合商品定位，画面能传达穿着情境 |
| 多人关系 | 每个人先过单人检查，再核共同地面、距离、互动和同场理由 |

## 把品类经验落到本款实物

品类只提示容易漏看的部位，真实商品决定这些部位应该长什么样。

- 夹克可以重点看领根、肩线、门襟/拉链连续性、袋口与手的遮挡、袖口/下摆收口。
- 衬衫可以重点看领座领尖、扣位、袖口开衩、下摆穿法和织面。
- 针织可以重点看针路尺度、前片与袖子的组织分区、领袖口和自然毛羽。

某一款有罗纹、三颗扣或特定接缝，不代表同品类全部如此。隐藏、遮挡或分辨率不足的细节应记“无法判断”，不能默认通过，也无需为本镜无关的背面扩展任务。

## 三种不能替代视觉结论的证据

1. **文件SHA相同**证明文件字节一致，不证明里面的商品正确。
2. **蒙版区外零变化**证明保护范围内像素未改，不证明蒙版范围选对，也不证明修改区和邻接处自然。
3. **API返回/原生程序保存成功**证明执行到达某一步，不证明成片好看、用户接受或已经上线。

实际案例中，助手曾放行前襟、领边或脸部融合，随后被用户指出问题；也有最终细节由用户手工修正的情况。记录应保留真实修正来源，不能把用户手工完成归为模型成功。

## 一次检查如何保持简洁

先看完整画面，判断构图、体态、材质块面和人物是否属于同一摄影空间；再看本次商品关键点与修改边界。返修前后同位并排，重点核目标和可能联动部位，避免只盯着刚改好的地方。

每项写三件事：商品/参考要求是什么、图中实际看到什么、结论为符合/不符/无法判断。把助手观察和用户反馈分别保存；部分认可只覆盖明确版本与维度。

例如，用户接受肤色变化，并不自动接受扣数错误；用户只退回其中两张，也不能借机替换其余已经接受的图片。按精确版本收尾，保留未完成项，而不是用一句“整体通过”掩盖差异。
