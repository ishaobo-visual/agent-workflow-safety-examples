# 局部返修：保住已经通过的部分

这篇文章总结服装图片实际返修中的判断方法。案例经过匿名化，没有公开原始图像，不能据此独立复核画面。下方任务表是说明用的虚构例子，不是历史原始提示词。

## 先把修改范围说清楚

收到“只改领口”时，先绑定用户正在评价的精确版本。其他已认可图片保持原版本，不从最近生成的文件重新挑选。对这一张区分目标错误、允许联动的部位和必须保留的事实。

| 项目 | 示例 |
| --- | --- |
| 输入版本 | image-A / revision-3，另存内容SHA |
| 目标修改 | 修正与实拍不符的领口结构 |
| 必要联动 | 领根、颈部接触阴影、领下第一段门襟 |
| 必须保留 | 人物身份、动作、已正确的袖口、裤子、场景 |
| 不确定项 | 遮挡部分无法从当前实拍确认 |
| 验收 | 与原版、商品证据并排核对；新图单独确认 |

“局部”不等于把蒙版压到最小。领口与颈部接触、手与口袋、拉链与相邻衣片可能需要一起修；只改一个点可能破坏连接关系。反过来，也不应因为存在联动就扩大为整个人或整张图重做。

## 两种保留要求应分别验证

- **正常观看保持**：原人物、肤色、动作、场景看起来仍一致。生成细节可能发生变化，是否接受由具体任务决定。
- **像素精确保留**：指定区域必须与原图一致。需要同坐标、正确蒙版及实际输出比较；它只证明该区域的像素关系。

用户已经按正常观看认可的版本，不能被事后增加的逐像素标准否定。用户明确要求完整人物冻结时，也不能用一个只覆盖人物中心的矩形零差证明整个人物都没变。

## 历史反例教会了什么

1. **保护区零变化，修改区仍可能错。** 实际返修曾保住区域外像素，却遗漏前襟重复、拉链错位和衣片连接。技术指标成立，整图仍被退回。
2. **脸部像了，融合未必自然。** 裁脸生成后缩放、位移和羽化回贴，可能产生头颈错位、肤色/光线差异或边缘穿帮。不能只看五官和边界指标。
3. **目标问题改善，其他材质可能退步。** 有局部移手或修脸的编辑，伴随衣料、裤料、石材出现新的卷曲细纹。复查必须包含原本正确且可能受影响的区域。
4. **超分不自动纠正结构。** 上游已有的错误可能被延续或强化，应回看原母版定位，而不是只归咎于最后一步。

这些是具体条件下的失败，不能推导成“所有局部修复都失败”或“必须永远重生成”。

## 何时调整路线

每轮记录原版、候选、参考用途、实际修改与新回归。若相同条件反复出现同类问题，先判断机制是否改变：参考是否仍给错纹理提供依据、相邻结构是否被不合理地锁住、供体是否能在原画面自然衔接。

可以重新划定联动范围、换有效参考，或从最后干净母版重建；选择哪条取决于具体证据。重建整图就明确说是新成图，不能称为原图无损局部修改。只将真实通过的版本及认可范围登记为成功，未采用的候选保留为对照。
